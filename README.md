# prince.dev — Modern Developer Portfolio

A responsive, high-performance personal developer portfolio website engineered with **HTML5**, **CSS3**, and **Vanilla JavaScript**.

## 🚀 Live Preview
- Fast, accessible, and responsive across all devices (Desktop, Tablet, Mobile)
- Ambient animations, dark/light theme switcher, interactive project modals, and direct mail dispatch

## 🛠️ Tech Stack
- **Markup & Semantics**: HTML5 (Accessible, SEO-optimized, OpenGraph meta tags)
- **Styling**: Vanilla CSS3 (Custom Design Tokens, Glassmorphism, CSS Grid & Flexbox)
- **Scripting**: Vanilla JavaScript ES6+ (Typewriter effect, Modal controller, Filter pills, ScrollSpy)
- **Icons & Typography**: FontAwesome 6, Google Fonts (Outfit, Plus Jakarta Sans, Fira Code)

## 💻 Local Setup
1. **Direct Preview**: Double-click `index.html` in any browser.
2. **Local Web Server**: Double-click `run_website.bat` or run:
   ```bash
   node server.js
   ```
   Then navigate to `http://localhost:3000`.
